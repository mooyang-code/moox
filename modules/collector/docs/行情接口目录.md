运行时目录的权威入口是 `internal/sources/catalog/catalog.go` 的 `Default()`。下表只列当前登记的 Go 工厂；登记、Provider 的能力声明和市场路由放行是不同层，不能仅凭源文件存在认定某个市场已可采集。

## 配置位置

各市场的参数、路由与数据源运行参数在 `config/markets/<市场>/`（`market.yaml`、`route.yaml`、`sources/*.yaml`），编在二进制里；A 股、港股、美股股票的 K 线来源由 `route.yaml` 按频率分候选链，crypto 与 A 股的指数、可转债固定用标签指定的来源。币安的 REST 端点与 WS 地址在 `configs/sources/market/binance.yaml`。交易日历只用内嵌的 `packages/marketcalendar`，交易桶统一由 `packages/barclock` 判断。A 股任务创建还会单独校验 Provider、市场与频率；当前不能把适配器声明的全部频率直接当作任务支持范围（例如通达信声明了 15m、30m、1h、1w，但 `route.yaml` 只有 1m、5m、1d 的候选链）。

仓库里未登记到上述默认运行时目录的适配器（例如 `internal/sources/bond/tdx`）不构成可用入口。AkShare、QUANTAXIS、easy_tdx 只作为接口语义参考，Collector 不依赖这些 Python 库。

## 启用前核验

核对完整 OHLCV、amount 是否存在、量额单位、时间标签、已闭合语义、历史范围、分页上限与错误处理，并确认目标出口可用。源码里的 `enabled` / `shadow` / `catalog_only` 是代码声明，不等于真实行情验收结论；各市场的实测结论见 `docs/模块/采集.md` 第 4、4c、4d 节。
