# 行情接口目录

运行时目录的权威入口是 `internal/sources/catalog/catalog.go` 的 `Default()`。下表只列当前登记的 Go 工厂；登记、Provider 的能力声明和市场路由放行是不同层，不能仅凭源文件存在认定某个市场已可采集。

| --- | --- | --- |

## 配置位置

各市场的参数、路由与数据源运行参数在 `config/markets/<市场>/`（`market.yaml`、`route.yaml`、`sources/*.yaml`），编在二进制里（含币安的 REST 端点与 WS 地址 `config/markets/crypto/sources/binance.yaml`）；A 股、港股、美股股票的 K 线来源由 `route.yaml` 按频率分候选链，crypto 固定用标签指定的来源；A 股的指数、可转债没有登记数据源。交易日历只用内嵌的 `packages/marketcalendar`，交易桶统一由 `packages/barclock` 判断。K 线任务创建时按与取数相同的口径校验频率：按路由分配来源的看 `route.yaml` 有没有该频率（例如通达信声明了 15m、30m、1h、1w，但 `route.yaml` 只有 1m、5m、1d），其余看来源声明的 `KlineSpec.Frequencies`。

AkShare、QUANTAXIS、easy_tdx 只作为接口语义参考，Collector 不依赖这些 Python 库。

## 启用前核验

核对完整 OHLCV、amount 是否存在、量额单位、时间标签、已闭合语义、历史范围、分页上限与错误处理，并确认目标出口可用。目录登记只表示代码可用，不等于真实行情验收结论；各市场的实测结论见 `docs/模块/采集.md` 第 4、4c、4d 节。
