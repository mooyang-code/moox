# 行情接口目录

运行时目录的权威入口是 `internal/sources/catalog/catalog.go` 的 `Default()`。下表只列当前登记的 Go 工厂；登记、Provider 的能力声明和市场路由放行是不同层，不能仅凭源文件存在认定某个市场已可采集。

| 市场 / 品种 | Provider / Source | 当前代码声明与用途 |
| --- | --- | --- |
| crypto / spot | `binance/spot_http` | REST K 线、标的快照与 WS 收盘推送 |
| crypto / swap | `binance/swap_http` | U 本位永续 REST K 线、标的快照与 WS 收盘推送 |
| stockcn / equity | `sina/stockcn_minute_http` | 分钟适配器，Provider 声明 enabled；市场验证配置仍标 catalog_only，实际候选链以 route.yaml 为准 |
| stockcn / equity | `tencent/stockcn_http` | enabled；上游不给成交额时写缺失值，不用 close × volume 估算 |
| stockcn / equity | `eastmoney/stockcn_http` | enabled；行情、标的快照 |
| stockcn / equity | `tdx/normal_7709` | enabled；TCP 普通行情 |
| stockcn / equity | `baidu/stockcn_http` | shadow；是否执行受路由模式与候选链控制 |
| stockcn / convertible_bond | `eastmoney/convertible_bond_http`、`sina/convertible_bond_http` | catalog_only，不能视为已放行的默认采集源 |
| stockcn / index | `eastmoney/index_http`、`sina/index_http`、`tencent/index_http`、`csindex/index_http` | catalog_only |
| stockcn / index | `cni/index_cni_http`、`sw/index_sw_http` | catalog_only |

行情源配置在 `configs/sources/market/`，A 股路由与验证配置在 `config/markets/stockcn/route.yaml`、`provider-validation.yaml`。A 股任务创建还会单独校验 Provider、市场与频率；当前不能把适配器声明的全部频率直接当作任务支持范围。

仓库中仍有港股、美股、日线与其他品种适配器或参考实现，但未登记到上述默认运行时目录的组合不构成可用入口。AkShare、QUANTAXIS、easy_tdx 只作为接口语义参考，Collector 不依赖这些 Python 库。

## 启用前核验

核对完整 OHLCV、amount 是否存在、量额单位、时间标签、已闭合语义、历史范围、分页上限与错误处理，并确认目标出口可用。源码里的 `enabled` / `shadow` 不是本次真实行情验收结论；本次文档审查未执行外部行情或 SCF 调用。
