MooX/初始化

    腾讯云账号

    MooX 部署在你自己的腾讯云账号里：行情采集用云函数，服务器也要在这个账号下。填好密钥后，下一步会自动识别服务器的地域和规格。

    当前所有服务器需要部署在腾讯云上（轻量应用服务器或云服务器 CVM），只有因子机例外：它可以是家里或局域网里的 Linux 机器。

    其他云厂商正在支持中。如果你用的是小众云厂商，可以手动部署：参考 GitHub 源码里的 docs/部署与运维.md，自行初始化各个模块的配置。

    你在这里填写的所有内容，不会发给 AI，也不会发给 MooX 开发者。

    只留在这台电脑
    密码、密钥和整份配置都在本机用 AES-256 加密后保存，文件只有你本人能读；解密密钥放在系统钥匙串，不写进配置文件。
    SSH 密码不保存
    只用来第一次开通免密登录，用完即丢。
    换电脑能找回
    部署完成后，整份配置会用你设的管理员密码再加密一次，备份到你自己的管理后台。

    访问密钥

    一对 SecretId 和 SecretKey。建议给 MooX 单独建一个子用户，不要用主账号的密钥。

    查看腾讯云的官方说明

    1. 打开腾讯云控制台的 访问管理 → 用户列表，新建一个子用户（已有的话直接用）：选「快捷创建」，填好用户名后，点「访问方式」那一栏的编辑图标，只勾选「编程访问」后确定。
    2. 给它授权：点「用户权限」那一栏的编辑图标，在弹窗里搜索并勾选下面全部 6 个预设策略（可以点「复制全部策略名」后逐个粘贴搜索）；右侧「已选择」里出现 6 条后点确定，再点「创建用户」。

    3. 点进这个子用户，切到「API 密钥」页签，点「新建密钥」。
    4. 把弹窗里的 SecretId 和 SecretKey 复制到下面。SecretKey 只在创建时显示一次，关掉弹窗后就查不到了，请先保存好。

    也可以用主账号在 API 密钥管理 里创建，但主账号密钥权限过大，不推荐。

    服务器

    填写每台服务器的公网 IP 和 SSH 用户名，地域和规格会自动从腾讯云识别（因子机以外的服务器必须是第一步这个腾讯云账号下的）。服务会按用途自动装到对应的服务器上；下一步为它们开通免密登录。

    免密登录

    MooX 用本机的一把专用密钥登录各台服务器，每台只需开通一次：先确认主机指纹，再输入一次 SSH 密码装上公钥。密码只用这一次，不保存，也不会发给 AI。

    MooX 密钥

    只给 MooX 使用，没有就自动生成。管理台的网页终端也用它登录服务器。

    配置完成

    配置已加密保存在这台电脑上，可以关闭这个页面，回到 Agent 继续部署。

    以后想查看或修改配置，对 Agent 说「打开配置页」。换了电脑，对 Agent 说「恢复配置」，再用管理员账号登录管理台即可取回。

    所有数据加密保存在这台电脑上，不会发给 AI，也不会发给 MooX 开发者。
