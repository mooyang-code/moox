# Storage 概念与设计意图

- **Space**：业务命名空间。
- **DataSource**：外部数据来源。
- **Subject**：业务对象或标的。
- **Dataset**：可写事实集合，绑定唯一且不可修改的 DataNode。
- **Field**：Space 级字段定义。
- **DatasetColumn**：Dataset 对 Field/Factor 的引用。
- **View**：由一个主 Dataset 和可选次级 Dataset 组成的派生查询模型。

TimeSeries 的身份只有 Subject、Freq 和 UTC DataTime。Dimensions 已从事实身份中
删除；需要筛选或展示的值应使用 Field/Attribute。Record 使用调用方提供的
version，并按 UTF-8 字节顺序排序。

系统优先保证简单、可恢复的数据所有权：

- 一个 Dataset 一个 DataNode Owner；
- 一个 Dataset 一个事件 Subject；
- 一个串行 View Consumer；
- View 通过 A/B 整库重建，不维护来源 Sequence Progress；
- Pebble 是事实源，DuckDB/Bleve 可删除并重建。

具体实现见 [存储层最终架构](存储层架构.md)。
