# 策略模块前端交互优化计划

- 基线：`moox` 仓库 `feature/mooyang` 分支，前端目录 `web/src/views/strategy/`
- 参考：`web/src/views/factor/`（因子模块）
- 产出方式：Codex（gpt-6-astra，xhigh，只读）两轮方案讨论 + Claude 抽查与修订；本文为最终计划，尚未开始实施
- 说明：以下结论来自静态阅读，未运行应用与测试

## 1. 结论

策略模块的基础（竞态保护、结果摘要、操作面板、大量回放测试）可靠，**不推倒重来**。主要问题集中在三类：

1. 用户路径断裂：名称点击直接进编辑器、实例列表无快速查看、回放页创建表单常驻占位、筛选/选中/分页不在 URL，刷新或返回即丢上下文。
2. 状态反馈不可信：多资源共用 loading/error、账户读取失败被吞成"无账户"、降级提示一律建议"重新启用"。
3. 结果语义有误：「持仓变化」跨会话比较，且只比较标的集合，并非持仓。

策略：**先做一个独立 bugfix 包，再做 5 项交互 MVP**，不做总览与批量操作。

## 2. 因子模块可借鉴的模式（取其理念，不跨模块 import）

| 模式 | 策略侧采用方式 |
|---|---|
| 列表 → 只读详情抽屉 → 专项页面 | 定义列表、实例列表都增加只读抽屉 |
| 筛选「草稿 → 点击查询生效」 | 实例列表去掉 `@change` 自动请求与查询按钮并存的重复行为 |
| URL 作为选择的唯一来源 + query 白名单 | 三页建立 `parse/build query` 纯函数 |
| 禁用操作附原因 | 删除实例、创建前置缺失处加 tooltip 说明 |
| 单一空态 + 下一步入口 | 无空间 / 空列表 / 筛选无匹配 / 读取失败分别展示 |
| 状态读取时间 | 实例列表、快速详情、回放显示最近一次**成功**读取时间 |
| 工具栏「数量 + 说明 + 操作」 | 三页统一 |
| 公共 `CodeBlock` 展示并复制 YAML | 定义详情抽屉 |
| model 纯函数与单测同目录 | 新增逻辑均先落在纯函数 |

## 3. 已核实的事实（修正了第一轮的部分判断）

- **属实**：`buildResultInsights`（`model.ts:220`）无 `session_id`，跨会话比较，且只比较标的集合。
- **属实**：`store/modules/strategy.ts:130` 将定义读取异常吞为 `null`，详情页显示"定义已删除"。
- **属实**：策略新建/编辑/详情隐藏路由缺 `activeMenu`（因子有）；`strategy-instance-create.vue:131` 账户读取失败被 `.catch(() => [])` 吞掉。
- **撤回**："KeepAlive 导致离开页面后仍轮询"不成立。三页未设 `keepAlive`，卸载时均清理定时器。
- **修正**：`validateStrategy` 中非成功响应的 diagnostics 转换分支为**不可达代码**（`callControl` 先抛 `ControlRequestError`），但成功响应的 diagnostics 正常，失败信息也以 `err.message` 展示，影响小于最初判断；对应测试 mock 与真实调用契约不符。
- **关键依赖**：`layout/components/Main/index.vue` 以 `route.fullPath` 作 key，**query 变化会重建页面**，URL 化的前提是改为按 `route.path` 复用。

## 5. 页面设计

### 5.1 定义列表

- 列：名称/ID、DSL 摘要、版本、更新时间、操作（查看 · 编辑 · 更多[删除]）。
- 名称点击 → 右侧只读抽屉：基本信息、规则/标的池/bar 摘要、DSL 原文（可复制）、按钮 `编辑定义` `查看当前空间实例` `创建实例` `发起回放`。
- 空态只在表格 `#empty` 出现一次，提供「新建策略」；读取失败显示错误与重试，不同时显示"暂无"。
- 不做使用数量与全局搜索（API 无契约）。定义按**全局资源**处理，不宣称"未被引用可删除"。

| query | 取值 | history | 切空间 |
|---|---|---|---|
| `page` | 正整数，默认 1 | replace | 保留 |
| `definition_id` | 抽屉对象 | 打开/换对象 push；关闭 replace | 保留并重新读取 |

### 5.2 运行实例列表 + 快速详情

- 工具栏：数量、状态读取时间、刷新、新建实例；筛选 `定义 / 启用状态` 采用「草稿 → 查询生效」。
- 列：实例 ID/定义、View、模式/账户、启用状态与健康（分开展示）、更新时间、操作（快速详情、完整详情、更多[删除]）。
- 快速详情**只读**，仅查询实例，不加载定义/目标/历史结果；启停仍在完整详情中完成。含 `打开完整详情` `按实例会话回放`。
- 创建抽屉保留，改进：定义预填；模式拆为「仅计算 / 发送至交易模块」，后者再选账户；View、账户分别有加载/空/失败+重试；账户失败不阻断仅计算，且不静默改选；预检保持可选；创建后仍为停用并进入完整详情。
- 删除成功后补载当前页，末页为空则回上一页；禁用时显示"请先停用/会话释放中"。
- 定义目录加载失败只影响名称显示，不把整表标为失败。

| query | 取值 | history | 切空间 |
|---|---|---|---|
| `strategy_id` | 定义筛选 / 创建初始定义 | 查询 replace；跨页入口 push | 保留 |
| `enabled` | `true`/`false` | replace | 保留 |
| `page` | 默认 1 | replace，改筛选回 1 | 清除 |
| `instance_id` | 快速详情对象 | 打开/换对象 push；关闭 replace | 清除 |
| `create` | `1` | 打开 push；关闭 replace | 清除 |

`create=1` 与 `instance_id` 互斥。

### 5.3 回放页

- 创建改为**右侧抽屉**（来源 → View → 时间区间 → 手续费），移除常驻内联创建区；补「结束晚于开始」「手续费有限合法」校验，保留 UTC/上海日期说明。
- 布局：左侧记录列表（状态、来源、进度、分页）；右侧详情（状态/进度/区间、取消、指标卡、曲线、DSL 折叠、周期表）。
- 错误分区：列表失败在左侧、详情失败在右侧、表格失败在表格上方、创建错误在抽屉内；后台刷新失败保留旧数据。
- 保留现有 brief/full 分离、曲线增量合并、手动翻页优先、终态补刷新、取消后指标等待。**本期不改为并行加载**。

| query | 取值 | history | 切空间 |
|---|---|---|---|
| `replay_id` | 分析对象（唯一来源） | 用户选择 push；自动选择/创建完成 replace | 清除 |
| `page` | 记录列表页 | replace | 清除 |
| `bar_page` | 周期表页 | replace，换回放回 1 | 清除 |
| `create` | `1` | 打开 push；关闭 replace | 清除 |
| `strategy_id` / `instance_id` / `view_id` | **仅创建预填** | 入口一次性写入 | 清除 |

合并规则：显式 `replay_id` 直接读取，失败不回退第一条；无显式 ID 时首次列表成功后自动选第一条（replace）；预填只在建立创建上下文时应用，翻页/轮询不得覆盖草稿；创建期间用户另选过对象则不抢选；仅带预填的旧 URL 规范化为 `create=1`。

### 5.4 通用规则

- 首次空间初始化不得清除深链接参数，仅"A→B 实际切换"才清除。
- 沿用顶部空间，不增加 `space_id` query。
- 默认值不写 URL；非法页码/枚举统一规范化。
- DSL 文本、时间、手续费等表单输入不进 URL。

## 8. 测试策略

- 沿用 Vitest + Vue Test Utils + fake timers + deferred Promise 风格。
- 纯函数：query 规范化、来源互斥、表单校验、会话内结果比较。
- 组件：加载/空/错误互斥、字段错误、抽屉关闭重开、按行 pending。
- **路由集成测试必须用真实 memory router**（现有回放测试将 `useRoute()` 固定为 `{query:{}}`，无法证明刷新恢复、前后退与不重挂载）。
- 现有部分编辑器/创建组件测试为源码字符串断言，涉及的部分需改为真实交互测试。
- 每步运行受影响测试与类型检查；最终跑全量 Vitest 与策略 Playwright。

### 代码审查修复（codex 审查后）

高严重：

1. 回放页真实切空间时，不再按旧 URL 重新选中旧空间的回放（只有空间初始化才按 URL 恢复深链接）。
2. 创建抽屉经 `?create=1` 深链接首次挂载即打开时，会初始化表单并读取元数据（watch 加 `immediate`）。
3. 创建成功后不再发 `update:visible(false)`，避免父组件的"关闭"导航取消去详情页的导航。

中严重：待生效的 push 被后续写入打断时沿用 push；URL 去掉 `replay_id` 时回到默认选择；外部导航视同用户另选，发起回放完成后不再抢选；运行页连续切空间用代次保证只有最后一次读取；删除后"回退页码"与"关闭快速详情"合并为一次导航；抽屉只响应用户取消，不再响应关闭动画结束事件；定义抽屉随空间切换重新读取并静默处理切空间造成的取消；运行页挂载时清掉可能属于其它空间的旧实例。

另补回放页"状态读取时间"。尚未解决：回放页测试的假路由仍是同步生效（新增用例用异步开关覆盖关键竞态）；没有挂载真实 Main、守卫和 Tabs 的集成测试。
