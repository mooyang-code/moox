# 采集任务页交互优化方案

- 基线：`feat/collector-tasks-ux` 分支（基于 `main`，含已实施的 K 线合成）；页面 `web/src/views/collector/collection-tasks/`
- 关联：[K线合成设计](K线合成设计.md)第 6 节（合成控制台改造已在 main 实施：选源任务、推导预览、「新建合成」行操作、「合成来源」列、历史合成抽屉）
- 状态：**已实施**（2026-10-23，含后端 `keyword` 搜索参数；交互层改造与合成功能融合发布）

## 1. 现状问题（改前）

1. 检索不畅：仅有「按内部任务 ID 筛选」——task_id 是系统生成 ID，用户记不住；筛选不写 URL，刷新即丢；输入无回车触发。
2. 列表信息架构：10 列横向滚动 1600px；「结果状态」「最近数据时间」与「采集结果」tab 重复；列表加载后 `inspectCollectionTaskResults` 逐行调 `GetTaskDetail` 巡检（N+1）只为刷新这两列。
3. 操作列风险：5～6 个按钮平铺（禁用 / 新建合成 / 历史合成 / 修改 / 删除）；「禁用」无二次确认，误触即停采集；「删除」与普通操作平级。
4. 表单与弹窗层叠：新建 / 编辑是 860px 弹窗装 4 个分节 + 高级设置，纵向深滚动；输出字段选择器弹窗叠弹窗；编辑态一排禁用控件可读性差。

## 2. 改动明细

| 项 | 改动 |
| --- | --- |
| 搜索 | 输入框改 `keyword`（placeholder「搜索任务名称 / 任务 ID」），回车触发查询、allow-clear 清除即查；后端 `GetTaskListReq` 新增 `keyword` 字段，store 层对 `LOWER(c_task_name)` / `LOWER(c_task_id)` 做 `LIKE %kw% ESCAPE '\'`（转义 `%`、`_`、`\`），沿用存储侧 keyword 惯例 |
| URL 同步 | `keyword` / `dataType` / `enabled` / `page` 写入 query（`syncListQuery`），刷新、分享可还原；`taskId` 详情深链保留；切空间清空筛选（任务清单随空间变化） |
| 列调整 | 移除「结果状态」「最近数据时间」两列（信息归「采集结果」tab 与详情抽屉「运行信息」分组），保留「合成来源」「启用状态」列；横向滚动 1600 → 1250 |
| 巡检删除 | 删除 `inspectCollectionTaskResults` / `tasksNeedingResultInspection` 及列表页逐行 `GetTaskDetail` 调用 |
| 操作列 | 「新建合成」「修改」平铺；启停 / 历史合成（kline_resample）/ 删除收进「⋯」下拉，删除红色；启停先 `Modal.confirm`（文案说明后果），执行期间该行 loading（`togglingTaskId`） |
| 表单抽屉化 | 新建 / 编辑弹窗 → 右侧抽屉（680px，底部「取消 / 保存任务」，`saveEditor` 成功后手动关闭）；编辑态不可变项（数据类型、频率、标的、源采集任务）由禁用控件改**只读摘要**（`readonly-summary`），合成任务的推导参数（源数据集 / 源周期 / 序列标签）仍由预览 descriptions 只读展示；输出字段选择器改第二层抽屉，消除弹窗叠弹窗 |
| 详情抽屉化 | 详情弹窗 → 右侧抽屉（640px），分「基本信息 / 执行方式（含合成来源与源周期）/ 依赖它的合成任务（可点击定位）/ 输出字段 / 运行信息」五组；运行信息含结果状态、最近数据时间、准备信息 |
| 空态 | 无任务显示「还没有采集任务」+ 新建按钮；有筛选无结果显示「没有匹配的任务」+「清除筛选」 |

改动文件：`modules/collector/proto/collector.proto`（+`collectorgen`）、`internal/store/task.go`、`internal/rpc/service.go`、`internal/store/task_test.go`、`web/src/api/collector/index.ts`、`web/src/views/collector/collection-tasks/collection-tasks.vue`、`collection-task-params.ts`（删巡检）及两个测试文件。

保留不动：删除确认弹窗（radio 二选一）、合成表单的源任务选择与推导预览（main 已实现）、历史合成抽屉 `resample-jobs-drawer.vue`、`taskId` 深链、空间切换时关闭打开中的表单窗口。

与原型的差异：启停确认用 `Modal.confirm` 而非气泡（Popconfirm 嵌在下拉菜单项里有关闭时序冲突，`Modal.confirm` 是项目已有惯例）。

## 3. 后续可选项（本期不做）

- 详情「依赖它的合成任务」点击定位后可加列表行高亮闪烁（当前直接切换详情内容）。
- 「合成来源」列的源任务名做成可点击定位（当前为纯文本，源任务名可从 `sourceTasks` 查到）。
- 采集结果 tab 按设计稿 6.4 补合成标记与历史合成进度入口。

## 4. 明确不做

批量操作（任务量小）、列自定义 / 排序、列表自动轮询（结果状态移除后无实时性诉求）、i18n、合成任务拆独立页面（设计稿已否决——「一任务一结果」，列表 / 详情 / 删除 / 结果管理不重做一遍）。
