# 主机监控配置

MooX 主机监控使用单一数据链路：

```text
moox-host-agent -> EventBus -> moox-monitor -> MooX Storage
```

Admin 不采集主机指标，也不保存主机监控历史。管理台通过 Admin 控制网关调用 `moox-monitor`。

## Host Agent

Host Agent 仅支持 Linux `amd64` 和 `arm64`，采集 CPU、内存、文件系统、磁盘和网络指标。Agent 不使用 SQLite、outbox 或本地补发队列。

部署和配置参考：

- `skills/moox/references/host-agent.md`
- `skills/moox/scripts/hostagent-deploy.sh`

## EventBus

Host Agent 通过共享 EventBus 凭据连接 NATS JetStream。部署流程负责生成和分发凭据；轮换时由用户重新发布 Agent。

## Monitor

Monitor 消费 HostMetric，写入 Storage 后才确认 EventBus 消息。当前指标保存在 Monitor 内存中，历史通过 Storage 查询。

Monitor 提供：

- `ListHostAgents`：返回最近上报的主机和当前快照。
- `QueryHostMetricHistory`：返回指定 `agent_id` 最近 1 小时、24 小时或 3 天的历史。

历史查询会返回 `storage_available` 和 `data_gap`。指标不可用时前端显示 `--`，不会转换成零值。

## Storage

Host 指标统一使用 `space_id=moox_system`、`freq=1m`，写入以下 Dataset：

- `host_resource_v1`
- `host_fs_v1`
- `host_disk_v1`
- `host_net_v1`

逻辑 metadata 和本地 route 分开应用：

```bash
go run ./modules/cli/cmd/moox-cli metadata apply --file examples/metadata-monitor-host.seed.yaml
go run ./modules/cli/cmd/moox-cli metadata apply --file examples/metadata-monitor-host-local-route.seed.yaml
```

Storage 的 `view.maintenance.host_retention` 默认保留 72 小时，清理任务每小时执行一次。Monitor 历史 API 固定只查询最近 3 天。

## 管理台

管理台入口为 `/ops/resource-monitor`。页面使用 `agent_id` 选择主机，通过 Monitor API 展示：

- 实时 CPU、内存、文件系统和网络摘要。
- 文件系统、磁盘和网卡明细。
- 最近 1 小时、24 小时或 3 天趋势。
- 主机离线、Storage 不可用和历史缺口状态。
