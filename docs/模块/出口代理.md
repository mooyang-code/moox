# 出口代理（EgressProxy）

`moox-egress-proxy` 提供 `trpc.moox.egress.Proxy`：Collector 访问受限外部网络（例如 Binance）的唯一出口，同时承担域名解析。
原生 tRPC 只监听 loopback `11440`，主机网关按组件目录验证内部签名与方法权限，只允许 `collector` 调用，不需要额外的公网监听或
代理凭据。

代码位置：`modules/egressproxy`；服务与方法声明在 `packages/servicecatalog`。

## 1. 部署与端口

| 端口 | 监听 | 说明 |
| --- | --- | --- |
| `11440` | `127.0.0.1`，tRPC | `Do`、`ResolveDomains`，只经本机主机网关访问 |
| `11441` | `127.0.0.1` | `/healthz`、`/readyz`、`/metrics`，共享健康鉴权；启动需要 `MOOX_HEALTH_AUTH_ACCESS_KEY`、`MOOX_HEALTH_AUTH_SECRET_KEY`，部署设置 `MOOX_INSTANCE_ID` |

部署在能访问外部网络的主机上，每套环境一个实例（`replicas: single`）。

## 2. 接口

**`Do`**：只发送 HTTPS GET/POST。

- 目标由域名白名单约束：`config/app.yaml` 的 `domains` 支持精确 DNS 名与 `*.` 子域后缀，后缀不包含根域。
  路径与已编码的查询分别传入，不允许地址、端口或 URL 覆盖目标。
- 只转发 Accept、Accept-Language、Content-Type、User-Agent；不转发 Cookie、Authorization 或内部元数据，也不读取系统代理环境。
- 解析后直接连接经过检查的公网 IP，保留原域名的 TLS 验证与 SNI，不跟随重定向。
- 上游状态码（包括 429、5xx）原样返回，`ret_info` 只报告代理自身的错误。响应支持 gzip、deflate、Brotli 解压，解压后最多
  32 MiB；返回内容类型、缓存信息、Retry-After 与 Binance 用量头，去掉编码、长度、Cookie 和逐跳头。
- 限制：请求正文最多 1 MiB，查询与路径合计最多 16 KiB，头部最多 32 KiB；单请求预算最多 60 秒，调用方取消可提前结束。
  组件目录为 RPC 报文预留 48 MiB 预算，共享原生传输在启动前设置 64 MiB 帧上限，方法级目录限制仍然生效。

**`ResolveDomains`**：为 SCF 的 DNS 快照解析域名。独立的精确域名白名单（`dns.domains`，最多 16 个）、IPv4 公网地址过滤、
TCP 探测、延迟排序与缓存，每个域名最多返回四个 IP。HTTP 白名单与 DNS 白名单独立配置。

## 3. Collector 怎么用

Collector 用共享的 `gatewayclient` 以 `collector` 身份调用本机主机网关，由网关按目录转到出口代理所在主机；Binance 标的列表等
大响应也走这条路径。`ResolveDomains` 的结果由 Collector 的 DNS 定时器写入快照，供 SCF 就近选择。详见[采集](采集.md)。

## 4. 配置

程序使用 `--config config/app.yaml --conf config/trpc_go.yaml`，配置严格拒绝未知字段、重复键与额外 YAML 文档：

```yaml
domains: ["*.binance.com", "data-api.binance.vision"]   # HTTP 出口白名单
dns:
  domains: ["api.binance.com", "fapi.binance.com", "data-api.binance.vision"]
  lookup_timeout_ms: 1500
  probe_timeout_ms: 500
  probe_port: 443
  cache_ttl_seconds: 300
  max_ips_per_domain: 4
```

关闭时先撤下就绪状态，再停止 RPC 并释放 HTTP 空闲连接。

## 5. 指标

DNS 解析相关指标（`/metrics`）：

| 指标 | 含义 |
| --- | --- |
| `moox_egress_dns_resolver_requests_total` | 解析请求数 |
| `moox_egress_dns_resolver_failures_total`、`moox_egress_dns_resolver_unresolved_domains_total` | 解析失败、无法解析的域名数 |
| `moox_egress_dns_resolver_lookup_duration_seconds`、`moox_egress_dns_resolver_probe_duration_seconds` | 查询与探测耗时 |
| `moox_egress_dns_resolver_probe_failures_total` | 探测失败数 |
