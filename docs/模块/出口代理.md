# 出口代理（EgressProxy）

`moox-egress-proxy` 提供 `trpc.moox.egress.Proxy`：Collector 访问受限外部网络（例如 Binance）的唯一出口。
原生 tRPC 只监听 loopback `11440`，主机网关按组件目录验证内部签名与方法权限，只允许 `collector` 调用，不需要额外的公网监听或
代理凭据。

代码位置：`modules/egressproxy`；服务与方法声明在 `packages/servicecatalog`。

## 1. 部署与端口

| 端口 | 监听 | 说明 |
| --- | --- | --- |
| `11440` | `127.0.0.1`，tRPC | `Do`，只经本机主机网关访问 |
| `11441` | 模板为回环；原生安装渲染为 `0.0.0.0` | `/healthz`、`/readyz`、`/metrics`，共享健康鉴权；启动需要 `MOOX_HEALTH_AUTH_ACCESS_KEY`、`MOOX_HEALTH_AUTH_SECRET_KEY`，部署设置 `MOOX_INSTANCE_ID` |

部署在能访问外部网络的主机上，每套环境一个实例（`replicas: single`）。

## 2. 接口

**`Do`**：只发送 HTTPS GET/POST。

- 目标由域名白名单约束：`config/app.yaml` 的 `domains` 支持精确 DNS 名与 `*.` 子域后缀，后缀不包含根域。
  路径与已编码的查询分别传入，不允许地址、端口或 URL 覆盖目标。
- 只转发 Accept、Accept-Language、Content-Type、User-Agent；不转发 Cookie、Authorization 或内部元数据，也不读取系统代理环境。
- 解析后直接连接经过检查的公网 IP，保留原域名的 TLS 验证与 SNI，不跟随重定向。
- 上游状态码（包括 429、5xx）原样返回，`ret_info` 只报告代理自身的错误。响应支持 gzip、deflate、Brotli 解压，解压后最多
  32 MiB；正文不再做业务层压缩，大响应（如 17 MB 的现货 exchangeInfo）在 tRPC 帧层统一压缩，避免出口主机上行带宽受限时阻塞共享连接；返回内容类型、缓存信息、Retry-After 与 Binance 用量头，去掉编码、长度、Cookie 和逐跳头。
- 请求头只放行 `Accept`、`Accept-Language`、`Content-Type`、`User-Agent`，另外对 `api.binance.com`（且只对它）放行 `X-MBX-APIKEY`：
  币安行情数据类接口（如下架计划 `/sapi/v1/spot/delist-schedule`）要这个头，不要签名，值是只读 Key 的公开标识。
  Collector 侧（`httpclient` 的出口传输）与代理侧各有一份白名单，两边都只对这个域名放行这个头，其他域名、其他头一律丢弃；两侧的日志都不记录请求头的值。
- 限制：请求正文最多 1 MiB，查询与路径合计最多 16 KiB，头部最多 32 KiB；单请求预算最多 60 秒，调用方取消可提前结束。
  组件目录为 RPC 报文预留 48 MiB 预算，共享原生传输在启动前设置 64 MiB 帧上限，方法级目录限制仍然生效。

## 3. Collector 怎么用

Collector 用共享的 `gatewayclient` 以 `collector` 身份按目录选路：出口代理同机时连接本机 `11002`，
跨机时直接连接目标主机网关 TLS `11003`；主机网关本身不跨主机转发。Binance 标的列表等
大响应也走这条路径。详见[采集](采集.md)。

## 4. 配置

程序使用 `--config config/app.yaml --conf config/trpc_go.yaml`，配置严格拒绝未知字段、重复键与额外 YAML 文档：

```yaml
domains: ["*.binance.com", "data-api.binance.vision", "openapi.okx.com"]   # HTTP 出口白名单（openapi.okx.com 是 OKX 官方文档的 REST 地址，只用于公开的永续合约 instruments 请求）
```

HTTP 白名单来自 moox.toml 的 `[egress_proxy] http_domains`：`setup render-runtime-config` 同时渲染出口代理的 `domains` 和 Collector 的
`egress_proxy.domains`，两边必须一致——Collector 只把命中自己名单的请求交给代理，其余直连，只改代理一边不够。没写 `http_domains`
时用默认名单（`*.binance.com`、`data-api.binance.vision`、`openapi.okx.com`）。已经写了 `http_domains` 但缺 OKX 域名的环境，
`config set` 改不了数组，要用 `moox-cli config migrate --add-egress-domain openapi.okx.com` 追加（默认只预览，确认后加 `--yes`
写回；已在名单里的不重复），再重新渲染并发布出口代理与 Collector。

关闭时先撤下就绪状态，再停止 RPC 并释放 HTTP 空闲连接。
