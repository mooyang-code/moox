# 出口代理（EgressProxy）

`moox-egress-proxy` 替 MooX 内部组件访问国内连不上的外部 HTTPS 接口（目前是 Binance 的 REST 接口），并为 SCF
的 DNS 快照解析这些域名的可用地址。它部署在香港的 compute-1 上，只接受 Collector 经主机网关的调用。

代码位置：`modules/egressproxy`；协议在 `modules/egressproxy/proto/egress.proto`（生成代码在 `proto/egressgen`）。

## 1. 部署与端口

| 端口 | 监听 | 说明 |
| --- | --- | --- |
| `11440` | `127.0.0.1`，tRPC | `trpc.moox.egress.Proxy`，经主机网关访问；ACL 只放行 `collector` |
| `11441` | `0.0.0.0` | `/healthz`、`/readyz`、`/metrics`，需要 health HMAC，防火墙只对 control 开放 |

单份部署，部署位置由 `moox.toml` 的 `[placements]` 决定。Collector 与它不在同一台主机时，请求经 compute-1 的主机网关
`11003`（TLS）到达。

## 2. 接口

| 方法 | 说明 |
| --- | --- |
| `Do` | 发出一次 HTTPS 请求并把目标的响应原样返回。目标返回的 HTTP 错误（如 429、5xx）放在 `status` 里，只有代理自身出错时才设置 `ret_info` |
| `ResolveDomains` | 解析白名单域名，返回经过 TCP 探测的公网 IPv4 地址，按连接延迟排序；解析不到的域名放在 `unresolved_domains` |

`Do` 的约束：

- 只支持 `GET` 和 `POST`，`GET` 不能带请求体；
- `host` 必须是不带端口的域名，并且在 `http.domains` 白名单内（支持 `*.` 前缀）；
- `path` 以 `/` 开头，`path` 和 `query` 不能包含空白、`?` 或 `#`；
- 只转发白名单内的请求头（默认 `Accept`、`Content-Type`、`User-Agent`）；
- 单次超时不超过 60 秒，不填时用 `default_timeout`；响应体解压后不超过 32MB；
- 只发 HTTPS，不读代理环境变量。

## 3. Collector 怎么用

- **HTTP**：Collector 的 HTTP 客户端按 `egress_proxy.domains` 判断哪些请求改走出口代理（`egress_transport.go`），
  其余请求直连。白名单与出口代理的 `http.domains` 来自 `moox.toml` 的同一处配置。
- **DNS 快照**：Collector 定期调用 `ResolveDomains`，把结果写进 SCF 的 DNS 快照；出口代理没有给出的域名用本机解析补齐。
  出口代理给出的结果会落盘，Collector 重启后可以先用上次的结果兜底。

## 4. 配置

`config/app.yaml` 由部署工具按 `moox.toml` 的 `[egress_proxy]` 渲染：

```yaml
http:
  domains: ['*.binance.com', data-api.binance.vision]
  allowed_headers: [Accept, Content-Type, User-Agent]
  max_response_bytes: 33554432
  default_timeout: 15s
dns:
  domains: [data-api.binance.vision, api-gcp.binance.com, api.binance.com, fapi.binance.com]
  lookup_timeout: 1500ms
  probe_timeout: 500ms
  probe_port: 443
  cache_ttl: 300s
  max_ips_per_domain: 4
```

对应的 `moox.toml`：

```toml
[egress_proxy]
http_domains = ["*.binance.com", "data-api.binance.vision"]

[egress_proxy.dns]
domains = ["data-api.binance.vision", "api-gcp.binance.com", "api.binance.com", "fapi.binance.com"]
refresh_interval_seconds = 300
request_timeout_ms = 3000
lookup_timeout_ms = 1500
probe_timeout_ms = 500
probe_port = 443
cache_ttl_seconds = 300
max_ips_per_domain = 4
```

## 5. 指标

| 指标 | 含义 |
| --- | --- |
| `moox_egress_http_requests_total`、`moox_egress_http_request_duration_seconds` | `Do` 的请求数与耗时，按目标域名和结果区分 |
| `moox_egress_http_rejected_total` | 被拒绝的 `Do` 请求，按原因（`invalid`、`domain_not_allowed`）区分 |
| `moox_egress_dns_requests_total`、`moox_egress_dns_failures_total` | `ResolveDomains` 的请求与失败 |
| `moox_egress_dns_unresolved_domains_total` | 解析不到可用地址的域名 |
| `moox_egress_dns_probe_failures_total`、`moox_egress_dns_lookup_duration_seconds`、`moox_egress_dns_probe_duration_seconds` | TCP 探测失败与解析、探测耗时 |
