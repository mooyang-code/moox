# 前端（Web）

MooX 管理台基于 Vue 3、Vite 5、TypeScript、Pinia 和 Arco Design，源码在 `web/`；
静态资源由 `web-host/` 打包成单个 Go 二进制提供。

## 1. 访问链路

```text
浏览器 ─► moox-console-proxy :9527 ─┬─ /api/admin/* ─► Admin 管理入口 :11000
                                   └─ 其他路径 ─► moox-web-host :9528（静态资源与 SPA 回退）
```

- 前端只调用同源的 `/api/admin/{service}/{method}`，不直接访问各后端服务。
- Storage 统一走 `/api/admin/storage/{method}`，由 Admin 的 Storage BFF 映射到 Storage 服务；
  BFF 只开放管理台实际使用的方法。
- SSH 终端用 WebSocket `/api/admin/ssh/WsConnect`，先换取短时票据再连接。
- 每个管理请求都带会话签名和当前空间（`X-Space-Id`），见[管理后台](管理后台.md)。
- `web-host` 收到 `/api/*` 直接返回 404，避免误把它当成代理。

## 2. 页面

菜单由 `src/api/modules/system/static-menu.ts` 静态声明，路由在 `src/router/route.ts`：

| 菜单 | 页面 |
| --- | --- |
| 首页 | 总览 |
| 数据采集 | 数据源、数据对象、基础字段；采集任务（任务、任务实例、执行器即云节点、采集结果） |
| 因子计算 | 因子总览；因子定义（新建 / 编辑）；计算任务（任务、计算结果、补算） |
| 策略管理 | 策略定义、运行实例、实例详情 |
| 交易管理 | 账户、持仓、订单 |
| 资源与运维 | 监控告警（默认）；服务部署（按主机分组的服务、网关路由）；主机工作台（主机列表、SSH 终端、文件管理、主机监控）；存储（数据节点、归档文件） |
| 系统设置 | 业务空间、密钥 |

监控告警位于 `/ops/monitor`，服务部署位于 `/ops/deployments?tab=services|routes`。前者使用 Monitor 结构化概览，后者使用 SysDeploy v2 与共享组件目录；主机、部署和名称由 CLI/目录管理，页面只提供启停。受保护组件与 control 主机不显示停用开关，停用只撤下路由与健康检查。组件抽屉保留探测与 Reporter 的独立结论、实例和版本；告警的 host_id/component_id 可直接定位。

路由按服务、上游与限额分组，方法展开显示实际 ACL；调用方与方法筛选作用于同一路由。定义、期望和已应用哈希分开展示；时间标为“本次编译”。待同步起点只使用与当前哈希匹配的 Monitor 持久观测，不由浏览器猜测。分页完整加载，读取错误明确显示；晚到请求和停用页面的轮询不会覆盖当前视图。

首页的服务在线与组件健康率来自 Monitor `summary.components`；主机负载、告警和链路也使用真实观测，缺失或读取失败显示未知/暂无。没有实时交易统计的部分只展示已登记账户数量，不填充示例数字。主机行跳到 `/ops/hosts?tab=monitor`，服务行定位到具体部署。

## 3. 开发

```bash
cd web
pnpm install
pnpm dev                 # 本地开发；需在 .env.development 设置 VITE_ADMIN_ORIGIN 指向一个 Admin 入口
pnpm test                # vitest 单元测试
pnpm build:prod          # vue-tsc 类型检查 + vite 生产构建
pnpm check:menu          # 菜单结构
pnpm check:deployments   # 服务部署、v2 API 与旧页面清理契约
```

前端在本机构建。当前分支的生产构建已在本机验证通过；Linux 编译机仅承担需要 CGO 的 Go 目标编译。

## 4. 发布

```bash
cd web && pnpm build:prod          # 生成 web/dist
cd ../web-host && make statik      # 把 dist 嵌入 internal/statik
cd .. && ./scripts/build/build.sh web-host  # 构建 moox-web-host
```

也可以直接使用 `./scripts/deploy/deploy-moox.sh --build-web-assets`。

`moox-web-host` 默认监听 `127.0.0.1:9528`（`MOOX_WEB_HOST_ADDR`），健康检查 `127.0.0.1:19527`
（`MOOX_WEB_HOST_HEALTH_ADDR`）。
