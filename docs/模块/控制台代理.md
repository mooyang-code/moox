# 控制台代理

控制台代理已接入组件目录、软件打包、原生 `setup bootstrap --stage control`、CA 授权与恢复、
Monitor 的进程及 HTTPS 页面探针。生产切换与完整系统验收另行确认；当前范围见[实现状态](../实现状态.md)，
历史决策与阶段证据见[执行计划](../2026-10-09-console-proxy-embedded-caddy-execution-plan.md)。

## 1. 进程与离线命令

`modules/consoleproxy` 构建为 `moox-console-proxy`，独立进程内嵌 Caddy `v2.11.4`。
`serve --config <path>` 运行服务；`validate --config <path>` 仅做配置校验与 JSON 构造，不 provision、不签发证书；
`check-state --config <path>` 只读核验现有 CA 证书/私钥、有效期、基线和已发布指纹，输出含公开指纹的 JSON（指纹值不含换行）；缺少 internal CA 会失败，不 provision、不写入基线。安装器用它核对停止前后、状态复制后和启动后的 CA 连续性。
`check-state` 要求持久基线已经存在。证书文件只接受单张 PEM，拒绝夹带其他信任根。
`initialize-state --config <path>` 显式离线初始化空状态，只加载 PKI，不监听 HTTP/健康端口、不申请站点证书、不安装系统信任；由持维护锁的部署编排调用，不能对运行中的状态使用。
`version` 输出组件版本、提交、构建时间与引擎版本；`stop-budget --config <path>` 输出外层启停等待秒数。

## 2. 配置与 CA 生命周期

配置见 `modules/consoleproxy/config/app.yaml`。相对状态路径以配置文件目录为基准；健康密钥沿用 `MOOX_HEALTH_AUTH_*`，
不写入发布配置。现有 CA 在 Caddy 加载前核对证书、私钥及持久指纹；常规启动不生成缺失 CA，也不自动补写历史基线。配置不再接受 `initialize_ca`。

**证书寿命**：internal 模式下叶子证书固定 90 天、中间证书 1 年（根证书约 10 年不变）。Caddy 默认叶子证书只有 12 小时、约每 8 小时换一次；
浏览器里只对“当前这张证书”点过继续访问、没有安装根证书的用户，每次换证后页面的后台请求（例如定时拉取接口）就会报 Network Error，
要刷新页面重新信任才恢复。拉长寿命后换证变得很少（到期前约 30 天自动续期）。**根本的办法仍是把已发布的根证书 `certs/caddy/root.crt`
安装到系统信任库**：根证书不变，换叶子证书和中间证书都不会再影响浏览器。
原生 bootstrap 在部署根 `identity/console-proxy/` 保存独立于发布和数据快照的私密授权凭据及完整初始材料。请求通过 `proxy_ca.create` 明确授权首次生成。凭据先记录 pending，完整材料同步并原子发布后记录 ready；生成阶段未发布的状态可重试，已消费材料丢失则拒绝重建。首次失败和强杀恢复复用同一 CA，升级校验其与持久身份一致并复制最新关闭状态，保留证书缓存。
public-only 安装不加载 PKI、不创建 internal CA；有 internal 历史时仍验证并保留原来的 CA 与持久指纹。

## 3. 访问与退出

公开入口默认 9527，只转发 `/api/admin/*` 和页面/静态资源。其他 API 与诊断路由返回 404。
诊断默认 `127.0.0.1:19528`，沿用 health HMAC 和共享健康 payload；TLS 握手通过后才就绪。
SIGTERM 关闭新请求准入，先排空已有 HTTP、流式及升级请求，再停止引擎与清理锁。

## 4. 部署与验证

软件包含在 `control` profile 中。core 阶段只准备制品，不启动代理；control 阶段根据控制主机地址渲染
公开 Host、TLS 模式与 Monitor 页面探针。internal 模式的首次创建必须显式传入授权，
普通 serve 不隐式修复身份。流程及参数见[部署与运维](../部署与运维.md)。

`make test-console-proxy` 执行模块测试和 vet；完整 Linux 场景还需 `test-unit-runtime-linux`、
`test-unit-bootstrap-linux`、`test-unit-core-linux` 的真实制品。已有软件包和测试入口不等于生产切换已完成。
