# 主机代理（HostAgent）

`moox-host-agent`（组件 `host-agent`，主机采集器）是每台 MooX 主机上自动部署的主机组件，采集本机资源并发布到
EventBus，由 Monitor 统一入库和告警。它不保存样本，也不内嵌 broker。

代码位置：`modules/hostagent`；快照协议在 `packages/hostmetricpb`。

## 1. 进程与端口

| 服务 | 端口 | 说明 |
| --- | --- | --- |
| `HostAgentMgr` | tRPC `11426` | `GetStatus`、`GetSnapshot`、`RunOnce`，经主机网关访问 |
| 健康检查 | `11425` | 绑定 `0.0.0.0`，只接受 health HMAC 签名，防火墙只对 control 开放，供 Monitor 跨机探测 |
| `sample.timer` | 每分钟（启动时立即执行） | 采集并发布一次主机快照，单次超时 30 秒 |

## 2. 采集

- 读取 CPU、内存、文件系统、磁盘 I/O 和网络计数器，算出使用率和速率。
- 每次采集生成一条主机快照事件（`MOOX_OBSERVABILITY`，凭据角色 `hostagent-publisher`），尽力发送，失败不重试。
- 定时和手动 `RunOnce` 共用同一把非重入锁，同一时刻只有一次采集；启动时的首次采集失败会让
  服务启动失败，由进程管理器重试。

## 3. 身份

每台主机有一个稳定的 4 位字母数字 `agent_id`，保存在 0600 身份文件
`~/.local/state/moox/hostagent/identity.yaml`（第 3 版：`version`、`agent_id`、`created_at`），
这是 HostAgent 唯一的持久状态。

每条快照还带上主机 ID（必填的环境变量 `MOOX_NODE_ID`，部署工具自动设置），Monitor 据此把主机快照和 SysDeploy 的主机
对应起来；缺少时 HostAgent 拒绝启动。

`config/app.yaml` 的 `host_name` 用于和 Admin 中的 SSH 主机名对应，操作系统主机名不同时需要设置。

## 4. 部署

主机采集器随主机一起部署，不用写进 `moox.toml` 的部署表：

```bash
moox-cli setup deploy-host --host <主机>                              # 部署整台主机
moox-cli setup deploy-host --host <主机> --components host-agent      # 只更新主机采集器
```

部署工具下发 EventBus 凭据（`secrets/eventbus/hostagent-publisher.yaml`）和 health HMAC，由主机运行脚本启动和
拉起。验证时使用 `moox-cli setup service status --host <主机>` 或 `moox-cli doctor diagnose --node <主机>`，
不要用未签名的远程 `curl` 访问健康端口。
