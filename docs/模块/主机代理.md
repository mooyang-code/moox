# 主机代理（HostAgent）

`moox-host-agent` 是每台 Linux 主机上的用户级服务，采集本机资源并发布到 EventBus，
由 Monitor 统一入库和告警。它不保存样本，也不内嵌 broker。

代码位置：`modules/hostagent`；快照协议在 `packages/hostmetricpb`。

## 1. 进程与端口

| 服务 | 端口 | 说明 |
| --- | --- | --- |
| `HostAgentMgr` | `11426` | `GetStatus`、`GetSnapshot`、`RunOnce` |
| 健康检查 | `11425` | 生产部署绑定 `0.0.0.0`，只接受 health HMAC 签名，供 Monitor 跨机探测 |
| `sample.timer` | 每分钟（启动时立即执行） | 采集并发布一次主机快照，单次超时 30 秒 |

## 2. 采集

- 读取 CPU、内存、文件系统、磁盘 I/O 和网络计数器，算出使用率和速率。
- 每次采集生成一条主机快照事件（`MOOX_OBSERVABILITY`，凭据角色 `hostagent-publisher`），尽力发送，失败不重试。
- 定时和手动 `RunOnce` 共用同一把非重入锁，同一时刻只有一次采集；启动时的首次采集失败会让
  服务启动失败，由进程管理器重试。

## 3. 身份

每台主机有一个稳定的 4 位字母数字 `agent_id`，保存在 0600 身份文件
`~/.local/state/moox/hostagent/identity.yaml`（第 3 版：`version`、`agent_id`、`created_at`），
这是 HostAgent 唯一的持久状态。

每条快照还带上主机 ID（必填的环境变量 `MOOX_NODE_ID`，部署脚本自动设置），Monitor 据此把主机快照和 SysDeploy 的主机
对应起来；缺少时 HostAgent 拒绝启动。

`config/app.yaml` 的 `host_name` 用于和 Admin 中的 SSH 主机名对应，操作系统主机名不同时需要设置。

## 4. 部署

```bash
./skills/moox/scripts/hostagent-deploy.sh user@host release.tar.gz \
  --eventbus-file credentials/hostagent-publisher.yaml \
  --ca-file credentials/eventbus-ca.pem \
  --health-auth-file secrets/health-auth.env
```

以 systemd 用户服务运行。验证时使用 `moox-cli doctor diagnose --node <node>`，
不要用未签名的远程 `curl` 访问健康端口。
