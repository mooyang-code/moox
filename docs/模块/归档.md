# 归档（Archive）

`moox-archive` 消费 Storage 的行变更事件，先写本地 Journal，再按月物化为 Parquet 文件；
启用 COS 时同步一份长期副本。当前环境未部署 Archive。

代码位置：`modules/archive`。

## 1. 进程与端口

| 服务 | 端口 / 周期 | 说明 |
| --- | --- | --- |
| 健康检查 | `11416` | `/healthz`、`/readyz`、`/metrics` |
| `materialize.timer` | 每 10 分钟（启动时执行） | 把 Journal 物化为 Parquet，清理 7 天前的去重回执，单次超时 120 秒 |
| `cos_sync.timer` | 每小时（启动时执行） | 同步 COS，未启用时空跑，单次超时 300 秒 |
| `metrics.timer` | 30 秒 | 上报指标 |

## 2. 数据流

```text
rows.upserted（MOOX_STORAGE，凭据角色 archive-eventbus）
  ─► 按配置的空间和数据集过滤
  ─► 本地 Journal（state_dir）+ 去重回执
  ─► materialize：按数据集、标的、月份写 Parquet（root_dir）
  ─► cos_sync：上传到 COS（可选）
```

- 只归档 `archive.sources` 中列出的空间和数据集。
- Parquet 默认永久保留；COS 副本不会让本地文件自动删除，需要规划本地容量。
- 退出时停止消费，并在有界超时内最后 flush 一次；Timer 失败不会终止事件消费。
- 单进程调度，多副本部署需要自行保证只有一个实例运行定时器。

## 3. 命令行

`moox-archive-cli`：

| 命令 | 作用 |
| --- | --- |
| `backfill` | 从 Storage 读取历史区间补写 Parquet（必须显式确认） |
| `compact` | 合并分区文件 |
| `verify` | 校验 Parquet 文件 |
| `sync-cos` | 手动同步 COS |
| `status` | 查看归档状态 |

## 4. Storage 调用配置

常驻进程的文件注册、COS 同步和 CLI 历史回填统一使用 `gatewayclient`。`gateway_client` 只声明 `caller: archive`、Admin 分配的 `key_id`、`key_file`；主机 ID、私有 CA 和本机网关地址来自同一部署目录中的 `hostgateway/config/app.yaml`，目录缓存放在 `archive.state_dir/gatewayclient/directory.json`。跨主机经目标主机网关 TLS 11003，本机经 loopback tRPC，写请求不重试。

密钥路径相对模块配置文件，签名文件必须为 0600 普通文件。读取配置不要求私密文件存在，离线命令可以工作；需要远端调用时必须配置完整签名身份，且实时目录或有效缓存至少一个可用。回填保留 Storage 内部角色认证。
