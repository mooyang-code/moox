# 共享包

`packages/` 下是多个模块共用的 Go 包。每个包都是独立的 Go module，通过 `go.work` 组织。
共享包只放跨模块的契约和基础设施，不放某个模块独有的业务逻辑。

## 1. 协议（Protobuf）

| 包 | 内容 |
| --- | --- |
| `commonpb` | 公共的 `RetInfo`、错误码等 |
| `storagepb` | Storage 事件负载（行变更、周期完成、View 就绪等） |
| `marketfetchpb` | 采集批次完成事件 |
| `metricspb` | 服务指标快照事件 |
| `hostmetricpb` | 主机快照事件，以及 HostAgent 的 4 位 `agent_id` 校验 |
| `tradeeventpb` | Strategy 发给 Trade 的目标权重事件 |

各包下的 `Makefile` 负责重新生成代码。

## 2. 事件与消息

| 包 | 内容 |
| --- | --- |
| `events` | 事件注册表（名称、版本、负载、Stream、Subject 族）、编码解码和消费者封装；业务模块只能使用这里声明的事件 |
| `jetstream` | JetStream 客户端、连接凭据、消费者与投递设置，以及测试用的内嵌 JetStream |

## 3. 网关与鉴权

| 包 | 内容 |
| --- | --- |
| `gatewayauth` | 面向节点网关的服务签名与校验（绑定目标节点、nonce 防重放） |
| `gatewayroute` | 路由表、路由快照校验和转发实现，由 Admin 和节点网关共用 |
| `servicecatalog` | 组件目录、逐方法 ACL、外部白名单与按主机编译路由；Doctor 已读取共享目录，网络服务接入仍在实施 |
| `requestauth` | MooX 规范的请求签名协议，`gatewayauth` 和 `healthz` 的签名都基于它 |
| `security` | 加解密等安全基础函数 |
| `healthz` | 统一的 `/healthz`、`/readyz`、`/metrics` 处理器和 health HMAC 校验 |

## 4. 运行时与可观测性

| 包 | 内容 |
| --- | --- |
| `timerjob` | 同步、可观测的 tRPC 定时器处理器：显式超时、跳过重入 |
| `trpcretry` | 幂等 tRPC 读调用的有界重试 |
| `report` | 模块健康检查清单、数据集健康策略和数据集指标定义，Monitor 和各模块共用 |
| `doctor` | 诊断引擎；从 `servicecatalog/catalog.yaml` 生成现有 Manifest 接口并校验发布副本，供 `moox-cli doctor` 使用 |
| `notification` | 企业微信、飞书告警发送 |
| `clsreporter` | 腾讯云日志服务（CLS）的有界批量上报，SCF 使用 |

## 5. 领域工具

| 包 | 内容 |
| --- | --- |
| `marketcalendar` | 交易日历（加密货币 7×24、A 股等） |
| `routeprobe` | 行情源访问通道的探测与结果模型（HTTP、HTTPS、TCP） |
| `tdx` | 通达信行情协议客户端，Collector 用于 A 股数据 |
| `cloudprovider` | 云厂商抽象及腾讯云实现（SCF、COS 等），CloudNode 和 CLI 使用 |
| `pyruntime` | Go 与 Python worker 的常驻进程池、JSON 帧协议和模块注册，Factor 使用 |
