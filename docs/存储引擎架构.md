# Storage 引擎架构

事实层和派生层严格分离：

| 引擎 | Owner | 数据 |
| --- | --- | --- |
| Pebble | `storage-node` | Field/Attribute 与原子 Outbox |
| DuckDB | `storage-view` | TimeSeries View A/B 文件 |
| Bleve | `storage-view` | Record View A/B 全文索引 |
| SQLite | `storage-primary` | Metadata v4 |

Pebble 使用保持字节顺序的 Tuple Codec。TimeSeries Key 的 Dataset 后紧跟 UTC
`bucket_start`，因此可以有界执行 `DeleteRange`。Record 的 version 按 UTF-8
顺序读取最大值。

DuckDB 和 Bleve 都直接持久化行，不再使用 MemoryEngine JSON 全量快照。View
实时写和 Backfill 使用同一字段 Upsert 语义；Backfill 只填缺失值。

当前 Delivery 的全部 Active 写入成功后才 ACK；临时失败保持 Delivery 并发送
`InProgress`，永久无效消息执行 `Term`，不会释放后让后续事件越过。

完整生命周期见 [存储层最终架构](存储层架构.md)。
