# Storage 服务架构与部署

标准部署包含三个角色：

| 进程 | `MOOX_STORAGE_ROLE` | 默认端口 |
| --- | --- | --- |
| `moox-storage-primary` | `primary` | Metadata `20100`、PrimaryStore `20101`、Health `20210` |
| `moox-storage-node` | `node` | DataNode `20107`、Health `20212` |
| `moox-storage-view` | `view` | DataView `20103/20202`、ViewIndex `20104`、Health `20211` |

三个二进制来自同一 `cmd/server`，角色必须由环境变量明确指定。部署脚本使用
`--with-storage-node` 打包独立 DataNode。

必填凭证：

```text
MOOX_STORAGE_NODE_AUTH_SECRET
MOOX_STORAGE_PRIMARY_AUTH_SECRET
MOOX_STORAGE_VIEW_AUTH_SECRET
```

Primary 节点表：

```text
MOOX_STORAGE_NODE_TARGETS=storage-node-0=ip://127.0.0.1:20107
```

View 依赖：

```text
MOOX_STORAGE_METADATA_TARGET=ip://127.0.0.1:20100
MOOX_STORAGE_PRIMARY_TARGET=ip://127.0.0.1:20101
MOOX_STORAGE_EVENTBUS_URL=nats://127.0.0.1:4222
```

生产环境不得使用 node ID、固定示例值或空字符串作为 secret。
