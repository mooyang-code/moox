# Storage PB Protocol Design

当前 Storage 协议不保留旧架构别名。

| Proto | 职责 |
| --- | --- |
| `rows.proto` | `RowKey`、字段级 Upsert 和查询结果 |
| `data_node.proto` | DataNode 精确读写、状态和桶清理 |
| `primary_store.proto` | Metadata 校验后的用户写读边界 |
| `dataset_fields_changed.proto` | 每 Dataset 字段变更事件 |
| `view_index.proto` | ViewIndex Prepare/Apply/Stat/Remove/Query |
| `view.proto` | DataView TimeSeries 查询和 Record 搜索 |
| `metadata.proto` | Metadata CRUD、View Revision 和 Build CAS |

协议不包含：

```text
ShardKey / ShardRow / ShardTarget
Dimensions
RowMarker / content_hash
node_sequence / source_sequence
DatasetProgress / ViewIndexSourceProgress
ScanRows / Snapshot / DeleteRows
```

DataNode 写入使用 `RowFieldUpsert`。ViewIndex 使用 `LIVE_WRITE` 和 `BACKFILL`；
Backfill 不覆盖非空实时值。所有请求中的 `auth_info` 都由对应服务校验。
