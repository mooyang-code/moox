# 云节点工具栏布局设计

## 目标

重新组织云节点页面的标题、操作按钮和筛选控件，降低按钮过多造成的拥挤感，同时保持现有功能和交互行为不变。

## 页面结构

页面内容按以下顺序纵向排列：

1. 独立标题行，仅展示“云节点”。
2. 操作工具栏，依次展示批量新增、批量部署、批量删除、云账户管理、代码包版本。
3. 筛选工具栏，依次展示云账户、节点 ID、地区、节点类型、节点状态和查询按钮。
4. 批量任务或选中状态提示，仅在现有业务条件满足时展示。
5. 节点表格。

## 视觉规则

- 标题不与任何按钮或筛选控件共用一行。
- 操作工具栏和筛选工具栏均左对齐，并允许自动换行。
- 标题到操作工具栏、两条工具栏之间、筛选工具栏到表格或状态提示之间均使用 `8px` 间距。
- 保留现有按钮颜色：新增为绿色、查询为蓝色、部署为橙色、删除为红色、管理入口为描边按钮。
- 桌面端优先保持每条工具栏单行；空间不足时在组件边界内自然换行，不产生页面横向溢出。
- 移动端保持相同的信息顺序，控件自动换行且页面可纵向滚动。

## 行为边界

- 不改变按钮的显示条件、禁用条件、事件处理和接口调用。
- 不改变筛选字段、查询逻辑、表格列、分页或批量任务提示。
- 不新增下拉菜单，不隐藏低频操作，不将批量按钮改为条件出现。

## 验证

- 更新布局契约测试，断言标题、操作工具栏、筛选工具栏和表格的顺序及 `8px` 间距。
- 运行前端完整单元测试和 production build。
- 使用桌面与 390px 移动视口检查工具栏换行、横向溢出和纵向滚动。
- 部署后在目标页面验证最终布局和 web-host 健康状态。
