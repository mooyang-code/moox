# 存储管理页标签栏操作区设计

## 背景

“主存节点”“主存路由”“归档文件”页面在全局标签栏下方单独占用一整行工具栏。工具栏只有右侧控件，左侧形成大面积空白，并将提示信息和数据表格向下推移。

本次调整只优化三个存储管理页的工具栏布局，不改变接口、表格、弹窗或业务行为。

## 目标

- 将页面操作控件放入全局标签栏右侧，删除空白工具栏行。
- 保留三个页面现有的刷新、新增、筛选和调试功能。
- 在关闭全局标签栏时仍显示全部页面操作。
- 在窄屏下保持标签和操作控件可访问，文本和按钮不重叠。

## 布局

全局标签栏分为三个区域：

1. 左侧路由标签区，占用剩余空间并允许横向滚动。
2. 页面操作区，显示当前路由提供的操作控件。
3. 全局操作区，保留现有的页面刷新和标签管理入口。

页面操作区与全局操作区之间使用分隔线区分作用范围。三个存储页面分别提供以下控件：

| 页面 | 页面操作 |
| --- | --- |
| 主存节点 | 刷新节点列表、新增节点 |
| 主存路由 | 刷新路由列表、新增路由 |
| 归档文件 | 数据集筛选、调试开关、刷新归档列表 |

页面原有的提示信息或表格紧接全局标签栏下方的内容容器，不再保留独立工具栏占位。

## 组件设计

### 标签栏挂载点

`Tabs` 组件在标签列表和全局操作之间提供稳定的 DOM 挂载点。挂载点只负责布局，不包含存储业务逻辑。

### 页面操作组件

新增一个轻量页面操作容器。容器接收操作内容，并根据全局标签栏状态选择渲染位置：

- 标签栏开启时，通过 Vue `Teleport` 将内容渲染到标签栏挂载点。
- 标签栏关闭时，在页面内容顶部原位渲染，保证操作能力不丢失。

各存储页面继续持有自身的加载、弹窗和筛选状态。操作容器不保存回调，不引入全局事件总线，也不把业务状态写入标签栏组件。

### 生命周期

路由页面激活时挂载自己的操作内容，停用或卸载时移除。`keep-alive` 页面不得在非当前路由中遗留操作控件。切换全局标签栏开关时，操作内容在挂载点和页面内布局之间切换。

## 响应式行为

- 标签列表使用可收缩宽度，并保留横向滚动能力。
- 页面操作区保持内容宽度，不挤压按钮文字。
- 归档页面的数据集筛选框在常规桌面宽度保持现有宽度；窄屏时缩短输入框。
- 页面操作区和全局操作区不换成多行，避免增加标签栏高度。
- 当视口无法同时容纳全部内容时，优先压缩标签列表，不隐藏当前页面操作。

## 可访问性

- 图标按钮保留 `aria-label` 和工具提示。
- 分隔线只承担视觉作用，不进入键盘焦点顺序。
- 标签、输入框、开关和按钮保持现有键盘操作能力。
- 页面操作从内容区移动到标签栏后，视觉顺序与 DOM 焦点顺序一致。

## 验证

- 为页面操作容器添加测试，覆盖标签栏开启、关闭和切换状态。
- 验证路由切换及 `keep-alive` 激活、停用时只显示当前页面操作。
- 运行前端类型检查、相关测试和生产构建。
- 使用浏览器检查三个页面的桌面和窄屏布局，确认原空白行消失，控件不重叠，提示条与表格上移。
- 验证刷新、新增、筛选和调试功能的行为与改动前一致。

## 非目标

- 不重做全局标签系统或侧边导航。
- 不调整存储页面的数据结构、接口和权限。
- 不统一改造其他业务页面的工具栏。
- 不删除全局标签栏已有的刷新和标签管理操作。
