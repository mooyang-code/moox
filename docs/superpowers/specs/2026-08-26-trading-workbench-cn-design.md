# 交易工作台中文高密度表格改版

## 目标

优化 `/#/trading/logical-accounts`、`/#/trading/positions`、`/#/trading/orders` 三个页面，保持现有 Arco Design 体系和后端接口不变，提升量化运维场景下的扫描效率、状态判断和常用操作可达性。

## 设计原则

- 三个页面采用统一的高密度运维表布局：页面标题、筛选工具栏、摘要指标、主表格、详情或操作反馈。
- 页面可见文案全部使用中文；交易所返回的账户 ID、订单 ID、交易标的代码等机器标识保留原始值。
- `Paper/Live` 显示为“模拟/实盘”，`SPOT/SWAP` 显示为“现货/合约”，状态、方向、订单类型和成交策略统一显示中文。
- 不增加后端接口，不保留旧字段兼容逻辑；沿用现有 URL 查询参数和请求竞态保护。
- 保持高风险操作的警告、二次确认和禁用条件，避免视觉优化削弱交易安全边界。

## 页面方案

### 逻辑账户

- 标题和副标题改为中文，顶部提供刷新和“新建逻辑账户”。
- 增加总数、运行中、已暂停、未就绪四项摘要指标。
- 主表按逻辑账户、账户类型、执行模式、结算资产、自动执行、就绪状态、成员数和操作展示。
- 增加状态和执行模式筛选，筛选仅作用于当前已加载列表，分页仍由服务端返回结果驱动。
- 详情抽屉按“账户状态”“资金曲线”“物理账户”“当前完整目标”“最近人工操作”分组，保留暂停、恢复、清仓、人工下单和成员管理。

### 持仓

- 顶部统一账户选择、交易标的筛选、查询、同步和刷新入口。
- 在主表上方增加权益、可用资金、未实现盈亏、持仓数量摘要；无账户时显示空状态。
- 现货使用资产持仓字段，合约使用方向、数量、开仓价、标记价、强平价、杠杆、保证金和未实现盈亏字段。
- 盈亏颜色遵循现有红涨绿跌约定，同时保留文字数值，不依赖颜色单独传达含义。

### 订单

- 标题改为“订单”，顶部保留账户选择、账户状态和刷新。
- “Orders/Fills” 改为“订单/成交”，筛选项改为交易标的、仅未完成、状态和时间范围。
- 订单表优先展示标的、市场、方向、类型、数量、成交进度、均价、状态和时间，支持对可取消状态执行撤单。
- 成交表使用成交编号、标的、方向、价格、数量、手续费、已实现盈亏、角色和成交时间。
- 订单和成交的分页状态彼此独立，切换账户或筛选时回到第一页。

## 响应式与可访问性

- 桌面端维持表格密度，窄屏工具栏自动换行，表格允许横向滚动但页面不产生额外横向滚动。
- 所有图标按钮保留 `aria-label` 或可见文字，按钮在加载期间禁用并显示加载状态。
- 空数据、未选择账户、加载失败和同步结果均提供明确中文反馈。

## 验证

- 运行交易页面相关 Vitest 与 Playwright 测试。
- 运行 `vue-tsc` 和生产构建。
- 使用桌面和窄屏浏览器检查三个路由，确认中文文案、表格滚动、筛选、分页和关键操作状态正常。
