# 字段管理工具栏 UI 优化设计

## 目标

字段管理页去掉重复的“字段管理”页内标题，将搜索、筛选和页面操作合并为一条紧凑工具栏，提升有效内容占比，并与 MooX 数据管理页面的操作密度保持一致。

## 布局

- 删除当前 `page-head` 及其中的页内标题。
- 工具栏采用左右分区的单行布局。
- 左区依次放置移动端字段组入口、字段搜索框、值类型筛选和状态筛选。
- 右区依次放置字段总数、刷新图标按钮和“新建字段”主按钮。
- 刷新继续使用图标和悬浮提示；新建字段保留图标与文字。
- 工具栏与字段工作台直接相邻，仅保留必要间距，不增加卡片或额外分隔容器。

## 响应式行为

- 桌面端保持单行，左区可收缩，右区不换行。
- 宽度不足时工具栏允许分区换行；搜索框优先占据可用宽度，筛选器保持可操作的最小宽度。
- 移动端字段组入口沿用现有逻辑，仅在侧栏隐藏时显示。
- 不允许搜索框、按钮、字段总数或筛选器相互遮挡。

## 行为边界

- 不修改字段查询、筛选、刷新、新建或空间切换逻辑。
- 未选择空间时仍显示现有警告，操作按钮保持禁用。
- 字段总数只在已选择空间时显示。

## 验证

- 运行字段工作台相关单元测试和前端生产构建。
- 使用桌面与窄屏视口检查工具栏对齐、换行和字段工作台尺寸。
- 确认标题不再出现，搜索框与操作按钮在桌面端处于同一行。
