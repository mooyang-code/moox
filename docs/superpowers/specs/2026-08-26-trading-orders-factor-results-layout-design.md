# 订单页对齐因子结果工作台布局

## 背景

`/#/trading/orders` 当前使用页面标题加 Arco `a-tabs` 组织订单和成交。页面功能完整，但与 `/#/factor/results` 的工作台布局不一致，标题区域、页签和内容滚动边界不够统一。本次只调整前端页面组织和视觉层级，不改变交易接口和业务行为。

## 目标

- 使用现有 `PageTitleTabs`，让“订单/成交”成为页面级标题页签。
- 保留账户选择、账户状态、刷新、筛选、分页和撤单等现有能力。
- 让内容区占满页面剩余高度，表格在内容区内滚动，避免页面整体出现多余滚动。
- 保持页面可扫描、低复杂度，所有页面可见功能文案使用中文。
- 通过 URL 保存当前页签和交易账户，便于从账户概览跳转后保持上下文。

## 非目标

- 不新增订单统计、侧边账户栏、批量操作或其他交易能力。
- 不修改后端接口、数据结构、请求参数语义和权限模型。
- 不引入新的页面级状态管理或通用工作台抽象。
- 不保留旧页签实现或为旧布局增加兼容分支；直接采用新页面结构。

## 页面结构

页面根节点使用与因子结果一致的全高 Flex 结构：

```text
orders-page
└── moox-inner
    ├── PageTitleTabs（订单 / 成交）
    └── orders-workbench-content
        ├── account-toolbar（账户、就绪状态、刷新）
        └── active-tab-panel
            ├── filter-bar
            └── table-region（表格或空状态）
```

### 标题页签

- 引入 `@/components/page-title-tabs/index.vue`。
- 页签项固定为 `{ key: "orders", label: "订单" }` 和 `{ key: "fills", label: "成交" }`。
- 当前页签从 `route.query.tab` 解析；仅 `fills` 解析为成交，其余值默认订单。
- 切换页签使用 `router.replace`，保留现有查询参数，至少不丢失 `trading_account_id`。
- 删除旧的页面级 `h2`、副标题和 Arco `a-tabs` 外壳，避免重复标题层级。

### 账户工具栏

- 保留现有交易账户下拉框、账户“就绪/未就绪”标签和刷新按钮。
- 工具栏位于标题页签下方，桌面端水平排列，窄屏自动换行。
- 账户切换仍通过 `trading_account_id` 路由参数驱动，并回到第一页、重新加载当前页签数据。

### 订单页签

- 保留交易标的、订单状态、仅未完成、时间范围和查询按钮。
- 保留订单表字段、状态中文映射、方向和状态颜色、分页和可取消订单的撤单按钮。
- 表格外包裹可伸缩的数据区域；数据区域内部处理纵向和横向滚动。

### 成交页签

- 保留交易标的、时间范围和查询按钮。
- 保留成交编号、交易标的、市场、方向、价格、数量、手续费、已实现盈亏、角色和成交时间字段。
- 成交分页与订单分页继续独立维护，切换页签不覆盖另一页签的分页状态。

## 状态与请求行为

- 沿用现有 `activeTab`、账户加载、请求竞态保护、空状态、加载状态和错误提示逻辑。
- 页签切换只触发目标页签的数据加载；账户不存在或未选择账户时清空数据并显示中文空状态。
- 查询条件的业务含义不变：订单和成交继续使用各自的时间范围，订单状态和“仅未完成”仅作用于订单查询。
- 撤单成功后仅刷新订单列表，不改变成交页签和其他筛选条件。

## 样式与响应式

- `orders-page` 和 `moox-inner` 设置 `height: 100%`、`min-height: 0`，并使用纵向 Flex。
- `orders-workbench-content` 使用 `flex: 1`、`min-height: 0`、与因子结果一致的顶部间距和 `overflow: hidden`。
- 每个页签内容使用纵向 Flex；筛选栏不参与表格滚动，表格区域占据剩余高度。
- 保持现有 Arco Design 变量、边框和间距，不新增渐变或装饰性卡片。
- 窄屏时账户控件和筛选控件宽度调整为 `100%`；表格允许横向滚动，但页面根节点不产生额外横向滚动。
- 按钮继续提供可见中文文字或 `aria-label`，刷新和查询按钮保留加载、禁用状态。

## 验证方案

- 更新页面布局契约：检查 `PageTitleTabs`、全高内容区、筛选栏间距，并确认旧 `a-tabs` 外壳已移除。
- 扩展交易工作台 Playwright 测试：验证订单默认页签、`tab=fills` 深链、页签切换、账户 URL 参数保留、查询/撤单入口和窄屏无横向溢出。
- 运行交易页面相关 Vitest、Playwright、`vue-tsc` 和生产构建。
- 使用桌面与窄屏浏览器检查中文文案、空状态、加载状态、分页和表格滚动边界。
