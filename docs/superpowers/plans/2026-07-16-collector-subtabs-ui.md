# Collector Secondary Tabs UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the collector workbench's pill-shaped secondary tabs with compact rounded rectangles while preserving their alignment and navigation behavior.

**Architecture:** Keep the existing Arco `rounded` tab component and override only its collector workbench presentation from the data-management page. The page-level style remains shared by the data view and data collection subtabs, while the existing source contract test guards the intended radius, colors, and spacing.

**Tech Stack:** Vue 3, scoped SCSS, Arco Design Vue, Vitest, Playwright, Vite

---
