# MooX 架构文档

> 一站式量化金融数据平台 —— 从数据采集、存储、管理到策略回测的完整闭环

MooX 是一个供个人使用的单用户量化金融平台，涵盖多源数据采集、统一存储、因子计算、策略、交易、归档和前端管理。项目采用 Go Monorepo 架构，通过 `go.work` 管理多个独立 Go Module，配合 Vue 3 前端。当前部署模型由一个中央 Admin 管理多台服务节点，每台服务器使用独立 Gateway 代理本机服务；单机部署是同一架构的特例。唯一登录用户拥有全部管理能力；系统保留完整认证和请求签名，但不建设 RBAC。

## 核心能力

| 能力域 | 说明 |
|--------|------|
| 多源数据采集 | 支持交易所（Binance 等）K 线、标的元数据采集，可扩展至行情、舆情等数据源 |
| 统一存储引擎 | 时序数据（K 线）、记录数据（标的信息）的统一存储与查询，支持列级更新 |
| 异步派生视图 | 写入主存后异步构建 OLAP 物化视图（DuckDB）和全文索引（Bleve） |
| 管理控制台 | 单用户登录、网关节点、服务部署信息和运维监控 |
| 节点服务网关 | 独立部署于每台服务器，只代理节点本机服务并缓存 Admin 下发的路由 |
| 事件驱动交易 | 账户与通道、订单执行、私有成交回报、双式账本、仓位和目标仓位调仓 |
| 前端工作台 | 数据浏览、采集器管理、策略配置、运维监控的可视化界面 |

## 技术栈

- **后端**：Go 1.24 + tRPC-Go + Pebble + DuckDB + Bleve + SQLite + GORM + MemoryBus/NATS
- **前端**：Vue 3.5 + TypeScript + Vite 5 + Arco Design Vue + Pinia
- **部署**：腾讯云 SCF（采集器）+ 中央控制节点 + 独立 Node Gateway 服务节点
