## 功能入口

| 服务 | 功能 |
| --- | --- |
| `TradeConsoleService` | 账户、模拟盘、逻辑账户、owner、人工订单、撤单和订单/成交/持仓查询 |

Strategy 通过 `LogicalAccountTargetRequested` 发布
`InstrumentTarget(instrument_id, quantity)` FULL 目标。Trade 保存每个逻辑账户当前唯一
目标，动态选择物理账户并逐步收敛。遗漏标的目标为零；空 FULL 表示全部目标归零。

人工操作不会绕过自动执行：

- 人工下单会暂停整个 LogicalAccount，并撤销活动 TARGET 订单。
- `FlattenLogicalAccount` 逐账户同步、撤单和清仓，记录 `OperatorAction`，最终保持
  PAUSED。
- Resume 会重新使用保存的最新目标，可能在人工清仓后重新开仓。

Live 交易默认关闭。Trade 只通过服务认证的 `GetSecretValue(secret_id)` 单条读取
`SecretMaterial`；普通 Secret 查询保持脱敏。Paper V1 只支持 MARKET。
