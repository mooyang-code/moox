## 功能入口

| 服务 | 功能 |
| --- | --- |
| `TradeConsoleService` | 执行账户、模拟盘、组合账户、owner、人工订单、撤单和订单/成交/持仓查询 |

Strategy 通过 `LogicalAccountTargetRequested` 发布
`InstrumentTarget(instrument_id, quantity)` FULL 目标。Trade 保存每个组合账户当前唯一
目标，动态选择执行账户并逐步收敛。遗漏标的目标为零；空 FULL 表示全部目标归零。

人工操作不会绕过自动执行：

- 人工下单会暂停整个组合账户，并撤销活动 TARGET 订单。
- `FlattenLogicalAccount` 逐账户同步、撤单和清仓，记录 `OperatorAction`，最终保持
  PAUSED。
- Resume 会重新使用保存的最新目标，可能在人工清仓后重新开仓。

Live 交易默认关闭。Trade 只通过服务认证的 `GetSecretValue(secret_id)` 单条读取
`SecretMaterial`；普通 Secret 查询保持脱敏。Paper 使用公共行情支持 MARKET 与简化
LIMIT 撮合：可立即成交的 LIMIT 按 taker 成交，GTC 延迟穿价后按 maker 成交，IOC/FOK
无法立即全量成交时整单取消；不模拟盘口深度、排队优先级或部分成交。
